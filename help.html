မေးလေ့ရှိသော မေးခွန်းများ (FAQ)

📌 စိန် ၁၀,၀၀၀ ဘယ်လိုရမလဲ?
Task များကို ပြီးဆုံးအောင်လုပ်ပြီး Screenshot များကို Giveaway စာမျက်နှာမှ တင်ပြရပါမယ်။ အတည်ပြုပြီးပါက စိန် ၁၀,၀၀၀ ရရှိမှာဖြစ်ပါတယ်။
📸 Screenshot ဘယ်လိုတင်ရမလဲ?
Giveaway စာမျက်နှာမှာ Screenshot ၂ ပုံ (၅ ပွဲဆက်တိုက်နိုင်ပုံနှင့် Layla MVP ၁၀ ကြိမ်ရပုံ) ကိုရွေးချယ်ပြီး User ID/Server ID ထည့်ကာ တင်ပြရပါမယ်။
⏳ အတည်ပြုချက် ဘယ်လောက်ကြာမလဲ?
ပုံမှန်အားဖြင့် ၂၄ နာရီအတွင်း အတည်ပြုပေးပါတယ်။ တစ်ခါတစ်ရံ ဝန်ပိုနေချိန်တွင် ၄၈ နာရီအထိ ကြာနိုင်ပါတယ်။
❌ ပယ်ချခံရရင် ဘာလုပ်ရမလဲ?
ပယ်ချခံရသည့် အကြောင်းရင်းကို ပြန်လည်စစ်ဆေးပြီး မှန်ကန်အောင်ပြုလုပ်ကာ ပြန်လည်တင်ပြနိုင်ပါတယ်။
🆔 User ID/Server ID ဘယ်မှာရှာရမလဲ?
MLBB ဂိမ်းထဲမှာ Profile ကိုဖွင့်ပြီး သင့် Avatar အောက်မှာ User ID နှင့် Server ID ကို တွေ့နိုင်ပါတယ်။
